Funil automático

Busca empresas, envia as sequências, responde com IA e leva para o agendamento no Calendly.
A rodada roda a cada 10 minutos pelo agendamento do GitHub.
De segunda a sexta, em horário comercial, o sistema faz uma rodada de envios a cada 20 minutos: envia as etapas que você aprovou e que já chegaram no dia. Fora desse horário nada é enviado. Toda manhã ele também busca empresas da campanha e prepara sequências novas para você aprovar.

Sua empresa

A IA usa estes dados para se apresentar e assinar as mensagens. Campos vazios não são citados.

Agendamento automático

O sistema roda sozinho a cada 10 minutos, de segunda a sexta: pelo agendador do banco (Supabase) e, de reserva, pelo GitHub. Não precisa de chave.
Ver execuções no GitHub

E-mail

Envio (SMTP) e leitura das respostas (IMAP). Os dados ficam nas variáveis de ambiente da Vercel (SMTP_HOST, SMTP_USER, SMTP_PASS, EMAIL_REMETENTE, IMAP_HOST).
Envia um e-mail de verdade e confere se dá para ler a caixa de entrada.

Calendly

Conecte para o sistema saber quando uma empresa marcou a reunião: ela vira "Reunião agendada", as mensagens param e você recebe um aviso. O link de agendamento fica em Automação.
Funciona no plano grátis: o sistema confere as reuniões a cada rodada. Nos planos pagos o aviso chega na hora.

WhatsApp pela UAZap

Conecte um número de WhatsApp para enviar as etapas e receber as respostas aqui no painel.
A UAZap usa o WhatsApp Web, que não é a API oficial. Para reduzir o risco de bloqueio do número, o sistema envia com intervalo, só em horário comercial, e para de mandar mensagens para quem pede para sair.

WhatsApp pela Evolution API

Alternativa à UAZap. Se as duas estiverem configuradas, o sistema usa a que estiver conectada.
Se a instância ainda não existir, o sistema cria (para isso use a API key global do servidor).
